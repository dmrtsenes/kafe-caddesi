# Fincan cafe cast

CC0 assets by Quaternius: Ultimate Modular Men, Ultimate Modular Women and Universal Animation Library.
Sources: https://quaternius.com/packs/ultimatemodularcharacters.html , https://quaternius.com/packs/ultimatemodularwomen.html , https://quaternius.com/packs/universalanimationlibrary.html

Selected casual/formal models share a compact cafe silhouette, petrol/cream/copper uniforms, vertex-color materials, and contact-aware carrying poses. No private comparison asset is included. Source geometry remains authored pack geometry. Unused animations are stripped, skeleton and retained tracks are unchanged.

Reproduce: node tools/prepare-cafe-cast.mjs
