# v5.2 Oyuncu Odağı — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tam kadrolu kafede oyuncunun varlığını yeniden belirleyici kılmak — boştaki gelir aktif oyuncunun ~%35'ine insin, personel taban tutsun, tavanı yalnız oyuncu açsın.

**Architecture:** İki parça. (A) Tezgâhtar rafı ancak %45'ine kadar doldurabilir; üst raf oyuncunun işi olur — mekânda görünür iş yaratır. (B) `World.tempo` (0..1) oyuncunun eylemleriyle dolar, boşta sönümlenir ve akış regülatörünün iki girdisine (`maxPending`, doğuş aralığı) çarpan olarak girer. Personelin akış katkısı kısılır, böylece boştaki taban düşer. Ayrıca sadakat hedefleri kendi geçmişine göre kalibre olur, ödüller ölçülen ₺/sn'ye çapalanır, prestij gerçek geç oyuna taşınır.

**Tech Stack:** TypeScript 5.6, Vite 5.4, three.js 0.169, Capacitor 8. Test koşucusu YOK — doğrulama `npm run typecheck`, `npm run build` ve tarayıcı konsolundan ölçüm (`window.__fincan`) ile yapılır.

Spec: `docs/superpowers/specs/2026-08-15-v5.2-oyuncu-odagi-design.md`

- [ ] **Step 2: `World`'e tempo alanlarını ve metotlarını ekle**

`src/sim/World.ts` içinde `realizedIncome = 0;` alanının (satır ~1645) hemen ardına:

```ts
  /**
   * KAFENİN RİTMİ (0..1) — bkz. BALANCE.tempo. Oyuncunun eylemleri
   * doldurur, boşta sönümlenir. KAYDA GİRMEZ (oturum başında 0).
   */
  tempo = 0;
  /** İçinde bulunulan saniyede tempoya eklenen toplam pay. */
  private tempoGainThisSecond = 0;
  /** Saniyelik bütçe penceresi. */
  private tempoWindow = 0;

  /**
   * Oyuncunun bir eylemi tempoyu besler. YALNIZ OYUNCU YOLUNDAN çağrılır —
   * personel yolundan çağrılırsa mekanik kendi kendini yer (personel zaten
   * boştaki tabanı üretiyor).
   *
   * Saniyelik bütçeyi aşan pay ATILIR, kuyruğa alınmaz: kuyruk spam'i
   * engellemez, yalnız geciktirirdi.
   */
  bumpTempo(amount: number): void {
    const room = BALANCE.tempo.maxGainPerSecond - this.tempoGainThisSecond;
    const applied = Math.min(amount, room);
    if (applied <= 0) return;
    this.tempoGainThisSecond += applied;
    this.tempo = Math.min(1, this.tempo + applied);
  }

  private updateTempo(dt: number): void {
    this.tempoWindow += dt;
    if (this.tempoWindow >= 1) {
      this.tempoWindow = 0;
      this.tempoGainThisSecond = 0;
    }
    this.tempo = Math.max(0, this.tempo - BALANCE.tempo.decayPerSecond * dt);
  }
```

```ts

     * v5.2 — PERSONEL TABANI, OYUNCU TAVANI ÜRETİR.
     *
     * Katkılar düşürüldü (tezgâhtar 0,8 → 0,45; barista 0,4 → 0,25).

    const kitchen = this.kitchenSpeedFactor();

    const done = Math.max(0, festivalCounter(state, prevDef) - state.festivalBase);
    if (prevDef.kind === 'item') state.festPrevItem = done;
    else if (prevDef.kind === 'clean') state.festPrevClean = done;
    else state.festPrevGuest = done;
  }
  state.festivalWeek = key;
  state.festivalBase = festivalCounter(state, currentFestival(now));
  state.festivalClaimed = false;
  return true;
}

/**
 * Festival hedefi: aynı TÜRDEN geçen haftanın gerçekleşeninin %90'ı,
 * türün tabanının altına inmemek kaydıyla. (Haftalık hedefle aynı gerekçe
 * — bkz. Daily.weeklyTarget notu.)
 */
export function festivalTarget(state: GameState, def: FestivalDef = currentFestival()): number {
  if (def.kind === 'item') return Math.max(120, Math.ceil(state.festPrevItem * 0.9));
  if (def.kind === 'clean') return Math.max(60, Math.ceil(state.festPrevClean * 0.9));
  return Math.max(12, Math.ceil(state.festPrevGuest * 0.9));
}
```

`weekScale` importu `Festival.ts`'ten kaldırılır; `hashDay` ve `FESTIVALS` zaten bu dosyada mevcut.
