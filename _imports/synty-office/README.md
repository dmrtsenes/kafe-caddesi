# Synty POLYGON Office Pack import

Place the downloaded **POLYGON Office Pack** archive, Unity package, or Source
Files folder in this directory. Keep the original filenames and directory
structure intact.

Target source:
https://syntystore.com/products/polygon-office-pack

After import, the integration will:

- select adult office workers and the two cleaner characters;
- exclude security, boss stereotypes, and unsuitable props from the random pool;
- convert selected FBX assets to web-ready GLB;
- retarget idle, walk, run, sit, carry, wipe, mop, and push animations;
- create separate curated pools for customers, cleaners, and service staff;
- retain the vendor license alongside the exported game assets.
